# Эмулятор сигналов ДВС на Arduino

## Описание

Этот проект представляет собой универсальный стенд-эмулятор на базе Arduino для диагностики и обслуживания двигателей внутреннего сгорания (ДВС). Устройство позволяет генерировать сигналы датчика коленвала, управлять реле-регулятором генератора, форсунками, а также работать с CAN-шиной. Управление и настройка производятся с помощью энкодера и I2C-дисплея.

## Основной функционал

- **Генерация сигнала коленвала**:
  - Типы: Индуктивный / Холла (эмулируется прямоугольным сигналом).
  - Шаблоны: 60-2, 36-1, 24-1 и другие (настраивается в коде).
  - Регулировка оборотов: от 0 до 8000 об/мин.
- **Генерация сигнала реле генератора**:
  - **Поддержка разных типов реле:**
    - **PWM (Япония):** Управление по ШИМ (D5).
    - **ON/OFF (Германия):** Простое включение/выключение (D6).
    - **CAN-based (Современные авто):** Управление по CAN-шине.
  - **Обратная связь:** Мониторинг напряжения на выходе реле через аналоговый вход (A1).
- **Управление форсунками**:
  - До 6 каналов.
  - Режимы: Одновременный, последовательный (в разработке).
- **Интерфейс**:
  - I2C дисплей 16x2 или 20x4.
  - **Расширенное меню:** Выбор режима работы генератора, настройка RPM и других параметров.
  - Энкодер с кнопкой для навигации и настройки.
- **CAN-шина**:
  - Эмуляция CAN-сообщений (передача оборотов, управление генератором).
- **Диагностика**:
  - Мониторинг напряжения и тока (требуется соответствующая обвязка).
- **Профили**:
  - Сохранение и загрузка настроек в EEPROM, включая тип генератора.
- **Логгирование**:
  - Запись параметров на SD-карту (требуется модуль и раскомментирование кода).
- **Часы реального времени**:
  - Поддержка модуля DS3231 для точного времени в логах.

## Подключение (пины Arduino)

| Назначение                   | Пин Arduino                                     |
| ---------------------------- | ----------------------------------------------- |
| **I2C (Дисплей, RTC)**       | A4 (SDA), A5 (SCL)                              |
| **Энкодер (CLK/DT/SW)**      | D10 / D11 / D12                                 |
| **Сигнал коленвала**         | D3 (PWM)                                        |
| **Реле генератора (PWM)**    | D5                                              |
| **Реле генератора (ON/OFF)** | D6                                              |
| **Форсунки (1-6)**           | D6, D7, D8, D9, D10, D11, D12, D13 (Пример)      |
| **Зуммер**                   | D4                                              |
| **Общий аналог. вход V**     | A6                                              |
| **Общий аналог. вход I**     | A7                                              |
| **Обратная связь генератора**| A1                                              |
| **CAN (MCP2515)**            | D13 (SCK), D12 (MISO), D11 (MOSI), D9 (CS)       |
| **SD-карта**                 | D13 (SCK), D12 (MISO), D11 (MOSI), D10 (CS)      |

**Внимание:** Существует конфликт пинов D10, D11, D12 между энкодером, SD-картой и CAN-шиной. Для одновременной работы всех модулей потребуется переназначить Chip Select (CS) пины для SD и CAN на другие свободные цифровые пины и внести изменения в код. Также пин D6 используется и для форсунки, и для ON/OFF реле - в реальной схеме их нужно разнести.

## Прошивка и настройка

1.  **Установите необходимые библиотеки** в Arduino IDE:
    - `LiquidCrystal_I2C`
    - `GyverEncoder`
    - `mcp2515` (например, от autowp)
    - `RTClib`
    - `SD`
2.  **Откройте проект** в Arduino IDE. Все `.ino` файлы должны находиться в одной папке.
3.  **Выберите плату** (например, Arduino Uno / Nano) и порт.
4.  **Скомпилируйте и загрузите** скетч.
5.  При первом запуске рекомендуется закомментировать вызовы функций, связанных с опциональными модулями (SD, RTC, CAN), если они физически не подключены, чтобы избежать зависаний.
